# LabCon

Sistema de Gerenciamento de Laboratorios de Pesquisa.

## Estrutura

- `index.html`: painel publico.
- `login.html`: acesso, cadastro e recuperacao de senha.
- `admin.html`: area administrativa.
- `src/`: scripts da aplicacao.
- `assets/css/`: estilos.
- `database/`: scripts SQL do Supabase.
- `docs/`: arquitetura e seguranca.

Leia `docs/ARQUITETURA.md` para entender as camadas do frontend e `docs/SECURITY.md` para a configuracao operacional.
